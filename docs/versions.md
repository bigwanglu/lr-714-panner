## 升级 / Upgrading

两个版本分开放置；不要用新版依赖覆盖旧版文件夹。先另存 Live Set，再加载 v2.1 检查信号、路由与运动。旧版工程、预设和自动化的无缝迁移尚未验证。

Keep the versions in separate folders. Do not overwrite the old version's dependencies. Save a copy of your Live Set, then load v2.1 and check signal, routing and movement. Seamless migration of older sets, presets and automation has not been verified.
