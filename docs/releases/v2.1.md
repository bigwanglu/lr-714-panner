## 中文

v2.1 将 Motion 轨迹设计加入原有的 7.1.4 声像工具，让空间运动成为可演奏的音乐维度。本版免费提供体验，并以 GitHub 预发布形式提供；真实音频和宿主运行测试尚未全部完成。

### 相对 v1.3.1 Public Beta 的主要变化

- 独立 Motion Editor，内置 **36 种轨迹**，包括连续随机路径与离散随机位置。
- **最多 8 笔手绘 XY 路径**；固定预置支持节点、宽高和位置编辑。
- 独立高度设计：Fixed、Up/Down、Rise/Fall、Random 和 Draw。
- **Free / Sync** 时钟：Free 每轮可直接输入 0.01–300 秒；Sync 支持音符、小节、Custom Bars，以及 Straight、Dotted 和 Triplet。
- PLAY / PAUSE、FORWARD / REVERSE、RESET 与主界面 Motion 开关。手动 XYZ 操作优先接管位置。
- 主界面新增 **XYZ / 3D 监视**，显示位置、轨迹和短期尾迹。
- 保留 Spread、Focus、LFE、X、Y、Z，以及测试音、十二路电平和六组输出路由。

本版同时包含对同步连接恢复、预置初始尺寸、默认路由等待和快速 Free 调度的修订。v2.1 是最后候选功能与布局的定版命名，不代表所有场景已完成验收。

### 安装与升级

下载 `LR_714_Panner_v2_1_0.zip`，不要选择 GitHub 自动生成的 “Source code” 压缩包。解压后保留完整目录，在 Audio Track 加载 `LR_714_Panner_v2_1_0.amxd`，将轨道 **Audio To 设置为 Sends Only**，并以低监听音量逐一核对输出。

旧版 v1.3.1 Public Beta 的下载和手册继续保留。升级前保存 Live Set 副本，两个版本分开放置，不覆盖旧版本依赖。

### 使用前请了解

- 当前设备使用首个输入声道；没有完整立体声输入保留或自动下混功能。
- 输出为离散 7.1.4 扬声器信号，不提供 Atmos 编码、对象元数据或 ADM 导出。LFE 为独立发送，本版不内置低通分频。
- 0.01 秒是可直接输入的周期下限。调度并非音频采样精度，仍有 80 ms 增益平滑；不保证可听声像精确每秒一百轮。鼠标拖动最低停在 0.1 秒的反馈尚未解决，可改为直接输入。
- PAUSE 暂停位置运动，不静音；RESET 归零相位，不清空轨迹。当前没有 Undo、删除笔画、清空画布或恢复原厂几何按钮。
- REVERSE 改变 XY 路径方向，不同时倒放高度曲线。
- Motion 状态有保存机制，恢复设计为 OFF、相位为 0；完整 Live 保存、关闭和重开仍需实测。Motion 自动烘焙为 XYZ 自动化尚未验证。
- 实际 Live 启动与重开、Sync 定位/循环/拍号变化、多实例、十二路听测、跨声卡自动路由及窗口持续置顶等测试尚未全部完成。默认路由应按实际声卡逐路确认，必要时手动设置。

现有模型、结构、模拟宿主与部分 Max 原生检查为本版提供了验证依据，但不等同于完整 Live 音频验收。使用前请阅读[中文完整手册](https://github.com/bigwanglu/lr-714-panner/blob/main/docs/v2.1/guide.zh-CN.md)。

## English

v2.1 adds Motion trajectory design to the existing 7.1.4 panner, making spatial movement part of musical performance. This version is available at no cost as a GitHub pre-release. Real audio and host-runtime testing are not yet complete.

### Main changes from v1.3.1 Public Beta

- A separate Motion Editor with **36 trajectories**, including continuous random paths and discrete random positions.
- **Up to 8 hand-drawn XY strokes**, plus node, width, height and position editing for fixed presets.
- Independent height design: Fixed, Up/Down, Rise/Fall, Random and Draw.
- **Free / Sync** timing: direct entry of 0.01–300 seconds per free cycle; note values, bars and Custom Bars in Sync, with Straight, Dotted and Triplet timing.
- PLAY / PAUSE, FORWARD / REVERSE, RESET and a main-device Motion switch. Manual XYZ changes take priority.
- An **XYZ / 3D monitor** for position, trajectory and a short movement trail.
- Retained Spread, Focus, LFE, X, Y and Z controls, test tone, twelve output meters and six routing pairs.

This version also includes revisions to host reconnection, initial preset sizing, default routing initialization and fast Free scheduling. The v2.1 version freeze retains the final candidate's functionality and layout; it does not imply that every use case has passed validation.

### Installation & upgrading

Download `LR_714_Panner_v2_1_0.zip`, rather than GitHub's automatically generated “Source code” archives. Keep the extracted folder intact, load `LR_714_Panner_v2_1_0.amxd` on an Audio Track, set **Audio To to Sends Only**, and check each output with your monitoring level lowered.

The v1.3.1 Public Beta package and manuals remain available. Save a copy of your Live Set before upgrading. Keep the versions in separate folders without overwriting older dependencies.

### Before using this version

- The device uses the first input channel. It does not preserve a complete stereo input or automatically downmix it.
- It provides discrete 7.1.4 speaker outputs, without Atmos encoding, object metadata or ADM export. LFE is an independent send, without a built-in low-pass crossover.
- 0.01 seconds is the direct-entry cycle minimum. Scheduling is not sample-accurate, and 80 ms gain smoothing remains in place; precisely audible 100-cycle-per-second motion is not guaranteed. A reported mouse-drag floor of 0.1 seconds remains unresolved; enter the value directly instead.
- PAUSE stops movement, not audio. RESET resets phase, not the drawing. There are no Undo, delete-stroke, clear-canvas or factory-geometry-reset buttons.
- REVERSE changes the XY traversal direction; it does not reverse the height curve with it.
- Motion state has a save/restore mechanism, designed to restore OFF at phase 0. A full Live save, close and reopen cycle still needs real-world validation. Automatic baking of Motion into XYZ automation has not been verified.
- Testing remains incomplete for Live initialization and reopening, Sync seeking/looping/meter changes, multiple instances, twelve-output listening, automatic routing on other interfaces and persistent window-on-top behavior. Check default routing against your actual interface and set it manually where needed.

Existing model, structural, simulated-host and selected native Max checks provide supporting validation; they do not amount to complete Live audio acceptance testing. Read the [English quick start](https://github.com/bigwanglu/lr-714-panner/blob/main/docs/v2.1/guide.en.md) before use.
