## 中文

v1.3.1 Public Beta 是一代公开测试版本，提供 Ableton Live / Max for Live 中的手动 7.1.4 声像定位与十二路输出。主界面包含 XY/Z 定位、Spread、Focus、LFE、X、Y、Z 六个主控、测试音、十二路电平和六组输出路由。自动 Motion 轨迹编辑与运动控制在 v2.1 中提供。

- [下载一代原始完整插件包](../../LR_714_Panner_v1_3_1_Public_Beta.zip)
- [中文安装与操作手册](../../使用说明_LR_714_Panner_v1_3_1.md)
- [历史中文项目介绍与作者说明](../../LR_714_LivePanner_CN.md)

解压后保留整个 `LR_714_Panner_v1_3_1_Public_Beta` 文件夹，将 `LR_714_Panner_v1_3_1.amxd` 加载到发声音轨。不要只复制 AMXD；同目录的 JavaScript 与 Max 补丁必须一起保留。将 Audio To 设置为 Sends Only，在 Live Output Config 中启用所需输出对，并按真实音箱接线核对 ROUTING。完整 7.1.4 监听需要至少十二路可用物理输出。

原始插件包与双语文件按原路径保留，供旧工程继续使用。此页只整理入口，版本名称保持 **v1.3.1 Public Beta**。如需试用 v2.1，请分开放置两个版本，并先另存 Live Set。

## English

v1.3.1 Public Beta is the first-generation public test version, providing manual 7.1.4 positioning and twelve outputs in Ableton Live / Max for Live. It includes XY/Z positioning, the six Spread / Focus / LFE / X / Y / Z controls, a test tone, twelve output meters and six routing pairs. Automatic Motion trajectory editing and movement control are available in v2.1.

- [Download the original complete first-generation package](../../LR_714_Panner_v1_3_1_Public_Beta.zip)
- [English installation and operating manual](../../Manual_7_1_4_LIVE_Panner_v1_3_1_EN.md)
- [Historical English introduction and author statement](../../LR_714_LivePanner_EN.md)

Keep the complete `LR_714_Panner_v1_3_1_Public_Beta` folder together and load `LR_714_Panner_v1_3_1.amxd` on the source Audio Track. The same-folder JavaScript and Max patch dependencies are required. Set Audio To to Sends Only, enable the required output pairs in Live Output Config and check ROUTING against the actual speaker wiring. A complete 7.1.4 monitoring system requires at least twelve available physical outputs.

The original package and bilingual files remain at their existing paths for older projects. This page organizes their navigation and retains the version name **v1.3.1 Public Beta**. Keep v2.1 in a separate folder and save a copy of your Live Set before trying it.
