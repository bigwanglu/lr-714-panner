## v2.1

Git tag: `v2.1.0` · Device: `LR_714_Panner_v2_1_0.amxd`

### 中文

在 v1.3.1 Public Beta 的声像与十二路输出基础上，加入完整 Motion 系统：36 种轨迹、最多 8 笔手绘路径、固定形状几何编辑、独立高度曲线、Free / Sync 时钟、运行控制与 XYZ / 3D 监视。

本版包含开发阶段对同步连接恢复、预置初始尺寸、默认路由等待及自由周期范围的修订。Free 每轮时长可直接输入 0.01–300 秒。v2.1 定版命名沿用最后候选版本的功能与布局。

实际音频与宿主运行验收尚未全部完成。[阅读完整更新与已知限制](docs/releases/v2.1.md)。

### English

Adds the Motion system to the panning and twelve-output foundation of v1.3.1 Public Beta: 36 trajectories, up to 8 hand-drawn strokes, fixed-shape geometry editing, independent height curves, Free / Sync timing, transport controls and an XYZ / 3D monitor.

This version includes development-stage revisions to host reconnection, initial preset sizing, default routing initialization and the free-cycle range. Free cycle time accepts direct input from 0.01 to 300 seconds. The v2.1 version freeze retains the final candidate's functionality and layout.

Real audio and host-runtime validation are not yet complete. [Read the full changes and known limitations](docs/releases/v2.1.md).

历史公开版本，保留原始插件包和中英文手册。包含手动 XYZ 定位、Spread / Focus / LFE、测试音、十二路电平与六组输出路由；不含 v2.1 Motion 系统。

Historical public version, retained with its original package and Chinese / English manuals. Includes manual XYZ panning, Spread / Focus / LFE, a test tone, twelve output meters and six routing pairs. It does not include the v2.1 Motion system.
